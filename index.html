The rule these wireframes exist to express

Company selection happens once, on the login page. Signing in resolves one tenant configuration bundle — branding, entity model, sources, taxonomy, page set, permissions — and the dashboard renders from it. There is no company switcher inside the product. A page outside a tenant's page set returns 404 rather than rendering empty.
